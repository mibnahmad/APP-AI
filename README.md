# LUMEA AI

Premium AI wall art generator built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and OpenAI-ready server routes.

## Features

- Prompt-driven AI wall art generation
- Premium artwork reveal and room mockups
- Try-before-you-buy unlock flow
- Local gallery, favorites, and prompt history
- Mocked checkout and print-ready export package

## Tech stack

- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- OpenAI SDK

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment

Create `.env.local` from `.env.example` and set:

- `OPENAI_API_KEY`
- `OPENAI_TEXT_MODEL`
- `OPENAI_IMAGE_MODEL`
- `PAYMENT_PROVIDER`

## Build

```bash
npm run lint
npm run build
```
